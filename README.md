# Telegram-бот Fable v2.0

Fable — многофункциональный игровой и модерационный бот для Telegram на Python, aiogram 3, SQLAlchemy 2 и PostgreSQL.

---

## 🌟 Ключевые возможности

1. **Единый глобальный профиль**:
   - Один профиль, общий баланс монет, банковский вклад, опыт, уровень, репутация, клан и биржа для пользователя во всех группах и в личных сообщениях.

2. **Экономика и Банк**:
   - Начисление кристаллов/монет за общение в чатах с защитой от накрутки (без автоматических мутов/банов).
   - Суточные проценты по банковским вкладам (от 0.5% до 5% в сутки в зависимости от баланса вклада) без риска повторного начисления за один день.
   - Переводы между игроками с дифференцированным налогом (0.5% до 10 000, 1% свыше 10 000).
   - Полный аудит и история финансовых операций.
   - Система репутации (`реп @user +` / `реп @user -`).

3. **Биржа и Маркетмейкер**:
   - Торговля биржевыми единицами (shares) за монеты.
   - Лимитные заявки с депонированием средств в стакане и рыночные сделки.
   - Matching Engine с приоритетом лучшей цены и времени (FIFO), поддержка частичного исполнения и безопасной отмены.
   - Автоматический маркетмейкер со спредом и подстройкой котировок под рыночный спрос/предложение.
   - Графики курса и объемов торгов (`биржа график`), отправляемые в Telegram в виде PNG.

4. **Игры**:
   - Одиночные: **Рыбалка**, **Охота**, **Слоты**, **Рулетка** (сжигание ставок, проверка шансов и кулдаунов).
   - **Дуэли** в группах: пошаговое прицеливание (до 10 раз, максимум 95% скрытый шанс), выстрел, сброс концентрации при промахе, защита от нажатий третьими лицами и повторных списаний.

5. **Кланы**:
   - Создание, рейтинг, состав, клановый чат (`клан чат <текст>`).
   - Удаление клана доступно **исключительно** его создателю с подтверждением.

6. **Топы и Рейтинги**:
   - Глобальные и локальные (для чата) рейтинги богатых, активных (день/неделя/месяц/всё время, 50 мест) и кланов.

7. **Локальная модерация и Иерархия прав (Уровни 1–5)**:
   - Уровни: Создатель (5), Старший админ (4), Админ (3), Модератор (2), Игрок (1).
   - Строгая защита субординации: запрет самоповышения и применения санкций к равным/вышестоящим.
   - Ручные муты, варны (30 дней, без авто-санкций), кики, баны, очистка сообщений, заморозка чата и слоумод.
   - Антиссылки с белым списком доменов.
   - Индивидуальная капча при входе с таймером и защитой от решения посторонними.
   - Правила чата с опциональным обязательным принятием перед началом общения.
   - Админ-панель `настройки` и пресеты (*Строгий*, *Обычный*, *Казуальный*).

8. **Глобальная панель владельца (ID 8039111975)**:
   - Доступ только владельцу в ЛС: список подключенных чатов, отключение/возобновление работы бота в конкретном чате, глобальный бан игрока, подтверждаемый сброс экономики и рассылка.
   - Логирование действий в `admin_action_logs` и Telegram log-канал.

## 🛠 Требования к окружению

- **Python**: 3.10+ (протестировано на 3.12)
- **PostgreSQL**: 14+ (протестировано на 16)
- **Библиотеки**: `aiogram>=3.0`, `sqlalchemy>=2.0`, `asyncpg`, `alembic`, `pydantic-settings`, `matplotlib`

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/derfg929-alt/Fable-v2-tg-bot-.git
cd Fable-v2-tg-bot-
```

### 2. Настройка виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
DATABASE_URL=postgresql+asyncpg://fable:fable@localhost:5432/fable
OWNER_ID=8039111975
LOG_LEVEL=INFO
TIMEZONE=Europe/Moscow

# ИИ-ответы (необязательно, но рекомендуется). Работает и без ключей —
# тогда бот отвечает встроенным офлайн-движком Fable.
# xAI Grok (приоритет):
GROK_API_KEY=xai-...
GROK_API_URL=https://api.x.ai/v1/chat/completions
GROK_MODEL=grok-4.7
# Groq Cloud (бесплатная альтернатива, используется если нет GROK_API_KEY):
GROQ_API_KEY=gsk_...
GROQ_API_URL=https://api.groq.com/openai/v1/chat/completions
GROQ_MODEL=openai/gpt-oss-120b
```

**Как подключить ИИ-ответы (Grok):**
1. Получите ключ на https://console.x.ai и вставьте его в `GROK_API_KEY`.
2. Запустите бота — в логах появится строка вида
   `AI подключён: провайдер=grok, модель=grok-4.7, ключ=xai-…5678`.
3. Если ключа нет, в логах будет предупреждение о работе офлайн-движка.

Приоритет провайдеров: xAI Grok → Groq Cloud → офлайн-движок. Если основная
модель недоступна (404), бот автоматически пробует резервные (`grok-4`, `grok-3`).

### 4. Применение миграций базы данных
```bash
alembic upgrade head
```

### 5. Запуск тестов
```bash
PYTHONPATH=. pytest tests/ -v
```

### 6. Запуск бота
```bash
python -m app.main
```

## 📜 Основные команды (без слэша)

- **Профиль**: `профиль`
- **Банк**: `банк`, `банк положить 100`, `банк снять 50`
- **Переводы**: `перевод @user 500` (или ответом: `перевод 500`)
- **История**: `история`
- **Репутация**: `реп @user +`, `реп @user -`, `реп @user`
- **Биржа**: `биржа`, `биржа купить 100`, `биржа продать 100`, `биржа заявка купить 100 1.2`, `биржа график`, `биржа отмена`
- **Игры**: `рыбалка`, `охота`, `слоты 100`, `рулетка красное 100`, `дуэль @user 100`
- **Кланы**: `клан`, `клан создать Название`, `клан вступить Название`, `клан чат текст`, `клан удалить`
- **Топы**: `топ`, `топ богатых`, `топ активных`, `топ кланов` (+ `чат`)
- **Модерация**: `мут 30м`, `размут`, `варн`, `кик`, `бан`, `разбан`, `админ список`, `правила`, `настройки`
- **Владелец (в ЛС)**: `настройки чаты`, `настройки стоп <chat_id>`, `настройки старт <chat_id>`, `глобальный бан <ID>`, `сброс экономики`
