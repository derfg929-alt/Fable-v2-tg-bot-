# Telegram-бот Fable v2.0

Fable — многофункциональный игровой и модерационный бот для Telegram на Python, aiogram 3 и SQLAlchemy 2.

Хранилище данных — **JSON-файл** (`data/bot_database.json`), который является
основным долговременным хранилищем: при запуске данные загружаются в локальную базу
SQLite, а при каждом изменении автоматически выгружаются обратно в JSON. PostgreSQL
не требуется (его можно включить через `DATABASE_URL` при необходимости).

Проект включает модуль **Fable Randomizer** — полноценную систему конкурсов и
розыгрышей призов с реферальной системой, проверкой подписок на Telegram-каналах,
взвешенным выбором победителей, административной панелью, Telegram Mini App и
серверным API.

## 🎲 Fable Randomizer (конкурсы и розыгрыши)

### Главное меню бота
После `/start` пользователь видит приветствие, автоматически сформированную
персональную реферальную ссылку и меню из восьми разделов (все кнопки
работают): 🎁 Конкурсы · 📣 Мои конкурсы · ➕ Создать конкурс · 👤 Мой профиль ·
👥 Пригласить друзей · 🏆 Победители · 📜 История участия · ℹ️ Помощь. Сразу под
приветствием отправляется inline-меню быстрых действий, а при настроенном
`MINI_APP_URL` добавляется кнопка открытия Mini App.

### Пользовательские команды
- `/start [ref_ID|c_ID]` — запуск бота, регистрация (обрабатывает реферальный
  диплинк `ref_<ID>` и диплинк на конкурс `c_<ID>`).
- `/contests` — список конкурсов (категории: активные / скоро начнутся / завершённые).
- `/join ID` — участие в конкурсе (с проверкой подписок на обязательные каналы).
- `/myref` — персональная реферальная ссылка (`https://t.me/<bot>?start=ref_<ID>`).
- `/profile` — профиль: имя, username, дата регистрации, приглашённые, участия, победы.
- `/history` — история участия с фильтрами (все / активные / завершённые / победы).
- `/winners` — список победителей завершённых конкурсов.
- `/help` — справка и кнопка «Связаться с поддержкой» (ссылка задаётся администратором).

### Конкурсы для своих каналов (владельцам)
Любой пользователь, который является **владельцем или администратором**
Telegram-канала, может создать конкурс для этого канала — без участия
администрации Randomizer. Права проверяются через Telegram Bot API
(`getChatMember`), подделать владение каналом нельзя.

- Кнопки «📣 Мои конкурсы» и «➕ Создать конкурс» ведут в пошаговый мастер
  (канал → название → описание → изображение → приз → число победителей →
  дата окончания → условия).
- Обязательная подписка на канал владельца добавляется автоматически.
- **Владелец канала не может участвовать и выиграть в своём конкурсе** (исключён
  из розыгрыша, при попытке участия получает понятное объяснение).
- Владелец управляет конкурсом: завершить, отменить, провести розыгрыш.
- **Полная статистика** по каждому своему конкурсу: активные участники, отмены,
  всего записей, пришедшие по приглашениям, победители, конверсия, длительность,
  история розыгрышей и **распределение регистраций по часам, дням и дням недели**
  (видно «пиковые» часы активности).
- Команды: `/mycontests` и `/createcontest` (или кнопки меню).

### Реферальная система
- За каждого нового приглашённого начисляется внутренний бонус **0.01%** к весу в
  розыгрышах (1 юнит), максимум **10%** (1000 юнитов).
- Запрещены саморефералы, повторное начисление и смена пригласившего.
- Бонус влияет только на конкурсы, в которых пользователь реально участвует;
  конкретные проценты пользователю не показываются.

### Алгоритм выбора победителей
Перед розыгрышем участники фильтруются (зарегистрирован, участвует, не заблокирован,
без дубликатов). Затем выполняется взвешенный случайный выбор без повторов:
базовый вес ненулевой у всех, реферальный бонус повышает шансы, но не гарантирует
победу. Каждый розыгрыш сохраняется в `draw_logs` (участники, веса, seed, версия
алгоритма, результат).

- Если запрошено больше победителей, чем участников, выбираются все участники
  (с предупреждением в логе).
- Повторный розыгрыш создаёт новый раунд и **сохраняет предыдущие результаты**.
  Доступны два режима: «Заново среди всех» и «Исключить прошлых победителей»
  (выбираются новые победители из оставшихся).
- Кнопка «🧾 Проверить честность» в карточке конкурса воспроизводит результат из
  сохранённого `seed` и подтверждает, что он не был изменён.

### Административная панель
Доступ только администраторам (владелец + записи в таблице `admins`). Команда `админ`
(или `/admin`, `админ панель`):
- Главная страница со статистикой (пользователи, конкурсы, участники, победители, приглашения).
- Создание конкурса пошаговым мастером (название, описание, изображение, приз, число
  победителей, даты, обязательные каналы, условия, текст публикации) с предпросмотром
  и кнопками «Опубликовать / Сохранить как черновик / Изменить / Отменить».
- Управление конкурсами: запуск, завершение, отмена, архивирование, удаление,
  изменение полей, участники, статистика, розыгрыш, повторный розыгрыш (в т.ч. без
  прошлых победителей) и проверка честности розыгрыша.
- Каналы: `/addchannel`, `/channels`, `/removechannel` (с проверкой прав бота).
- Пользователи: `/finduser ID` — профиль, приглашения, история, победы, блокировка/разблокировка.
- `/stats` — статистика проекта; `/mycontests` — список конкурсов администратора.
- `/adminhistory` — аудит действий администраторов (таблица `audit_logs`).
- Настройки (`adm_settings`): ссылка поддержки и включение/выключение каждого типа уведомлений.

### Уведомления
Автоматические уведомления о новом конкурсе, старте, скором окончании, завершении,
выборе победителей, успешной регистрации, необходимости подписки, изменении условий
и отмене конкурса. Повторная отправка одного события исключена уникальным ключом в
таблице `notifications`; каждый тип можно отключить в настройках.

### Telegram Mini App и API
Интерфейс — `mini_app.html`; серверный API — `app/api.py` (FastAPI + uvicorn,
запускается вместе с ботом на `API_HOST:API_PORT`). Разделы Mini App: Главная,
Конкурсы, Мои конкурсы, Профиль, Приглашения, Победители, История, Помощь. Все
данные берутся из БД через API. **Все запросы требуют валидный Telegram
`initData`** (HMAC-подпись токеном бота + проверка срока жизни); Telegram ID
берётся только из проверенных данных. Эндпойнт `/api/contests/{id}/stats`
доступен только владельцу конкурса или администратору.

### База данных
Новые таблицы: `contests`, `channels`, `contest_channels`, `entries`, `referrals`,
`winners`, `draw_logs`, `notifications`, `admins`, `settings`, `audit_logs`.
Для пользовательских конкурсов каналов добавлены поля `contests.owner_id`,
`contests.source_channel_id` и `channels.owner_id` (миграция
`d4e5f6a7b8c9`). Уникальные ограничения защищают от дублей Telegram ID,
повторных рефералов и участия.

Долговременное хранилище — **JSON-файл** `data/bot_database.json` (путь задаётся
`JSON_DATABASE_PATH`; `-` отключает JSON-синхронизацию). Все таблицы выгружаются в
него при каждом изменении и восстанавливаются при запуске, поэтому данные (включая
историю участия и результаты розыгрышей) сохраняются между перезапусками.
PostgreSQL опционален: задайте `DATABASE_URL`, и данные будут храниться в нём.

## 🌟 Ключевые возможности

1. **Единый глобальный профиль**:
   - Один профиль, общий баланс монет, банковский вклад, опыт, уровень, репутация, клан и биржа для пользователя во всех группах и в личных сообщениях.

2. **Экономика и Банк**:
   - Начисление кристаллов/монет за общение в чатах с защитой от накрутки (без автоматических мутов/банов).
   - Суточные проценты по банковским вкладам (от 0.5% до 5% в сутки в зависимости от баланса вклада) без риска повторного начисления за один день.
   - Переводы между игроками с дифференцированным налогом (0.5% до 10 000, 1% свыше 10 000).
   - Полный аудит и история финансовых операций.
   - Система репутации (`реп @user +` / `реп @user -`).

3. **Биржа и Маркетмейкер**:
   - Торговля биржевыми единицами (shares) за монеты.
   - Лимитные заявки с депонированием средств в стакане и рыночные сделки.
   - Matching Engine с приоритетом лучшей цены и времени (FIFO), поддержка частичного исполнения и безопасной отмены.
   - Автоматический маркетмейкер со спредом и подстройкой котировок под рыночный спрос/предложение.
   - Графики курса и объемов торгов (`биржа график`), отправляемые в Telegram в виде PNG.

4. **Игры**:
   - Одиночные: **Рыбалка**, **Охота**, **Слоты**, **Рулетка** (сжигание ставок, проверка шансов и кулдаунов).
   - **Дуэли** в группах: пошаговое прицеливание (до 10 раз, максимум 95% скрытый шанс), выстрел, сброс концентрации при промахе, защита от нажатий третьими лицами и повторных списаний.

5. **Кланы**:
   - Создание, рейтинг, состав, клановый чат (`клан чат <текст>`).
   - Удаление клана доступно **исключительно** его создателю с подтверждением.

6. **Топы и Рейтинги**:
   - Глобальные и локальные (для чата) рейтинги богатых, активных (день/неделя/месяц/всё время, 50 мест) и кланов.

7. **Локальная модерация и Иерархия прав (Уровни 1–5)**:
   - Уровни: Создатель (5), Старший админ (4), Админ (3), Модератор (2), Игрок (1).
   - Строгая защита субординации: запрет самоповышения и применения санкций к равным/вышестоящим.
   - Ручные муты, варны (30 дней), кики, баны на любой срок (`1 час`, `2 часа`, `20 часов`, `12 мин`, `2 дня`, `навсегда`), очистка сообщений, заморозка чата и слоумод.
   - Автоматический антиспам: детект флуда, повторов, **капса** и **спама эмодзи**, авто-мут с эскалацией до временного бана (`антиспам вкл`, `антиспам лимит 6 10`, `антиспам повторы 4`, `антиспам капс 0.7`, `антиспам эмодзи 15`, `антиспам срок 30м`, `антиспам действие бан`). Выключен по умолчанию.
   - **Антимат**: фильтр нецензурной лексики с распознаванием обходов (латиница-двойники, разделители, повторы букв), настраиваемое действие (`антимат действие удалить|варн|мут`) и свой список слов (`антимат добавить слово`). Выключен по умолчанию.
   - **Анти-флуд «пауза»**: минимальный интервал между сообщениями игрока (`антифлуд пауза 5`). Выключен по умолчанию.
   - **Авто-эскалация варнов**: настраиваемый лимит и наказание при его достижении (`варн лимит 5`, `варн действие мут|бан|кик`, `варн срок 1ч`, `варн эскалация вкл`); при двойном лимите — бессрочный бан.
   - Гибкий парсинг сроков: `мут 67` (67 минут), `мут 1ч 30м`, `мут 2д`, `бан навсегда`.
   - Массовая очистка: `чистка 50`, `чистка все 100`, ответом на сообщение — очистка сообщений конкретного игрока.
   - Авто-снятие истёкших мутов и временных банов фоновым воркером.
   - Логи модерации в лог-канал: `логи настроить ID`, `логи выкл`.
   - Фильтр ссылок с белым списком доменов (выключен по умолчанию; упоминания `@user` разрешены всегда).
   - Индивидуальная капча при входе с таймером и защитой от решения посторонними (`+капча` — включить, `-капча` — выключить; по умолчанию выключена).
   - Правила чата с опциональным обязательным принятием перед началом общения.
   - Админ-панель `настройки` с кнопками быстрого переключения и пресеты (*Строгий*, *Обычный*, *Казуальный*); полная справка — команда `модерация`.

8. **Глобальная панель владельца (ID 8039111975)**:
   - Доступ только владельцу в ЛС: список подключенных чатов, отключение/возобновление работы бота в конкретном чате, глобальный бан игрока, подтверждаемый сброс экономики и рассылка.
   - Промокоды: создание (`+промо КОД МОНЕТЫ [РЕЙТИНГ] [ЛИМИТ] [НА_ЮЗЕРА]`), список (`промокоды`), управление (`промо вкл/выкл/удалить КОД`); активация игроком — `промо КОД`.
   - Сводка модерации, статистика экономики и логи действий в админ-панели.
   - Логирование действий в `admin_action_logs` и Telegram log-канал.

9. **Умный ИИ Fable (память диалога)**:
   - Помнит, о чём говорили, отдельно для каждого чата и пользователя (`ai_conversations`).
   - Поднимает контекст беседы и отвечает по теме; команда `забудь` очищает память.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/derfg929-alt/Fable-v2-tg-bot-.git
cd Fable-v2-tg-bot-
```

### 2. Настройка виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
OWNER_ID=8039111975
LOG_LEVEL=INFO
TIMEZONE=Europe/Moscow

# Хранилище: по умолчанию SQLite + JSON (data/bot_database.json) — PostgreSQL не нужен.
# Для PostgreSQL раскомментируйте:
# DATABASE_URL=postgresql+asyncpg://fable:fable@localhost:5432/fable
JSON_DATABASE_PATH=data/bot_database.json

# Fable Randomizer: username бота (если пусто — определится через Telegram API)
BOT_USERNAME=
# Публичный HTTPS-адрес Mini App (например, https://ваш-домен/)
MINI_APP_URL=
# Серверный API и Mini App
API_HOST=0.0.0.0
API_PORT=8080
INITDATA_TTL_SECONDS=86400

# ИИ-ответы (необязательно, но рекомендуется). Работает и без ключей —
# тогда бот отвечает встроенным офлайн-движком Fable.
# xAI Grok (приоритет):
GROK_API_KEY=xai-...
GROK_API_URL=https://api.x.ai/v1/chat/completions
GROK_MODEL=grok-4.7
# Groq Cloud (бесплатная альтернатива, используется если нет GROK_API_KEY):
GROQ_API_KEY=gsk_...
GROQ_API_URL=https://api.groq.com/openai/v1/chat/completions
GROQ_MODEL=openai/gpt-oss-120b
```

**Как подключить ИИ-ответы (Grok):**
1. Получите ключ на https://console.x.ai и вставьте его в `GROK_API_KEY`.
2. Запустите бота — в логах появится строка вида
   `AI подключён: провайдер=grok, модель=grok-4.7, ключ=xai-…5678`.
3. Если ключа нет, в логах будет предупреждение о работе офлайн-движка.

Приоритет провайдеров: xAI Grok → Groq Cloud → офлайн-движок. Если основная
модель недоступна (404), бот автоматически пробует резервные (`grok-4`, `grok-3`).

### 4. Миграции базы данных (необязательно)
При использовании SQLite/JSON схема создаётся автоматически при запуске, миграции не
нужны. Они требуются только для PostgreSQL:
```bash
alembic upgrade head
```

### 5. Запуск тестов
```bash
PYTHONPATH=. pytest tests/ -v
```

### 6. Запуск бота
```bash
python -m app.main
```

Бот и серверный API Mini App запускаются одной командой: Long Polling Telegram и
HTTP API на `API_HOST:API_PORT`. Для Mini App укажите в BotFather адрес
`https://ваш-домен/` (эндпойнт `/` отдаёт `mini_app.html`, API — на `/api/...`).
